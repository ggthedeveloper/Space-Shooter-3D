# Space Battle Game Assets

This directory contains optional external static assets for Alien Assault 3D.

- **images/**: High-resolution banners, screenshots, or cockpit textures.
- **ships/**: Custom 3D starship models or textures.
- **enemies/**: Alien cruiser models and textures.
- **galaxies/**: Cosmic nebula textures and galaxy background maps.
- **weapons/**: Projectile sprites and particle textures.
- **audio/**: Pre-rendered audio tracks and SFX (in addition to the built-in procedural Web Audio synthesizer).
- **fonts/**: Orbitron, Exo 2, or custom sci-fi typography.

*Note: The core game is fully equipped with high-performance procedural Three.js geometry builders and a real-time Web Audio synthesizer, operating with zero external file loading latency.*
